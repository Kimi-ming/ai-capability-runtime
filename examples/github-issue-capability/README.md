# GitHub Issue Capability

该示例对应 Registry 条目：

```text
registry/developer-tools/github.create_issue/
```

它是 V1 的关键 proof-of-work，因为它覆盖：

- auth
- write permission
- human confirmation
- external API execution
- invocation logging

预期命令流程：

```bash
opencap install github.create_issue
opencap serve --mcp
```
