# 决策 0002：本地优先 运行时

日期：2026-05-07

## 状态

已接受

## 背景

OpenCap 可以从托管服务开始，但这会过早引入账户、计费、多租户、云安全和商业分发等问题。

作为开源项目，更好的切入点是让开发者在本地运行 Runtime，并把它接入 MCP-compatible Host。

## 决策

OpenCap V1 本地优先。

Runtime 状态位于：

```text
opencap.local/
```

V1 的第一种外部 API 认证方式是本地开发环境中的环境变量 API key。

## 影响

好处：

- 易于 clone 和试用
- 威胁模型更简单
- 不依赖托管账户
- 更符合开源采用路径

代价：

- V1 没有团队共享策略
- 没有远程安装分析
- 没有托管 OAuth broker
- 用户需要管理本地环境密钥
