# 开发环境

本文记录 OpenCap 的本地开发环境。项目当前推荐使用 conda 创建隔离环境，并在环境内运行 pnpm workspace。

## 创建环境

```bash
conda env create -f environment.yml
```

如果环境已经存在，可以直接激活：

```bash
conda activate ai-capability-runtime
```

当前环境路径：

```text
/opt/anaconda3/envs/ai-capability-runtime
```

## 版本要求

| 工具 | 版本 |
| --- | --- |
| Python | 3.11 |
| Node.js | 22 |
| pnpm | 9.15 |

`package.json` 声明的包管理器是 `pnpm@9.15.0`；conda-forge 当前安装的是 `pnpm 9.15.3`，属于同一 9.15 系列。

## 安装依赖

激活环境后运行：

```bash
pnpm install
```

## 常用验证

```bash
pnpm validate
pnpm test
pnpm build
```

## 注意事项

在这台 mac 上，如果使用 `conda run -n ai-capability-runtime node --version`，可能会因为 shell PATH 优先级拿到 Homebrew 的 Node。推荐使用 `conda activate ai-capability-runtime` 后再运行命令；必要时可以确认：

```bash
which node
node --version
pnpm --version
```

期望 `which node` 指向 `/opt/anaconda3/envs/ai-capability-runtime/bin/node`。
